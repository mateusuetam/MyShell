# MyShell

Este repositório contém o código da minha shell desenvolvida originalmente no meu repo pessoal e, posteriormente, seus arquivos e histórico foram extraídos para cá com o objetivo de preservar o histórico de desenvolvimento.

## Sobre o projeto

O principal objetivo deste projeto foi educacional. Ele serviu como um laboratório para aprimorar meus conhecimentos em programação, desenvolvimento de interfaces, arquitetura de software e organização e estruturação de projetos. Durante seu desenvolvimento, o projeto também serviu como espaço para experimentar diferentes abordagens e conceitos relacionados à construção de uma shell em um ambiente Wayland.

## Status

O objetivo original de aprendizado foi cumprido e, por esse motivo, o projeto está sendo arquivado. O código permanecerá público exclusivamente para consulta, referência e registro do processo de desenvolvimento.
